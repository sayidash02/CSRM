# Stakeholder 360 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish explicit relationships between modules and view a unified summary of interactions per stakeholder ("Stakeholder 360°").

**Architecture:** We will introduce a central `stakeholders` lookup table (like `pics`) to ensure consistent naming. Modules will link to this table. In addition, `daily_activities` will link to `stakeholder_engagement` and `csr_projects` will link to `grievance`. The UI will replace free-text fields with Searchable Comboboxes and add a Stakeholder 360 Profile page.

**Tech Stack:** Node.js, Express, Prisma, React 18, Vite, Radix UI.

- [ ] **Step 1: Create Controller**
```typescript
import { Request, Response } from 'express';
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

export class StakeholderController {
  static async getAll(req: Request, res: Response) {
    try {
      const stakeholders = await prisma.stakeholders.findMany({
        where: { is_active: true },
        orderBy: { name: 'asc' }
      });
      res.json(stakeholders);
    } catch (error) {
      res.status(500).json({ error: 'Failed to fetch stakeholders' });
    }
  }

  static async create(req: Request, res: Response) {
    try {
      const { name } = req.body;
      const stakeholder = await prisma.stakeholders.create({
        data: { name }
      });
      res.status(201).json(stakeholder);
    } catch (error) {
      res.status(400).json({ error: 'Failed to create stakeholder' });
    }
  }
}
```

- [ ] **Step 2: Create Routes**

const api = axios.create({ baseURL: '/api' });

export const getStakeholders = async () => {
  const { data } = await api.get('/stakeholders');
  return data;
};

  const { data } = await api.post('/stakeholders', { name });
  return data;
};

- [ ] **Step 2: Create React Query Hooks**
```typescript
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { getStakeholders, createStakeholder } from '../api/stakeholders';

export function useStakeholders() {
  return useQuery({
    queryKey: ['stakeholders'],
    queryFn: getStakeholders
  });
}

export function useCreateStakeholder() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: createStakeholder,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['stakeholders'] });
    }
  });
}
```
