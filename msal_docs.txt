### Initialize ConfidentialClientApplication with Secrets or Certificates

Source: https://github.com/azuread/microsoft-authentication-library-for-js/blob/dev/lib/msal-node/docs/initialize-confidential-client-application.md

Instantiate a ConfidentialClientApplication object for MSAL Node. This example shows how to configure authentication using either a client secret, a client certificate, or a client assertion callback. It utilizes dotenv for secure secret management.

```javascript
import * as msal from "@azure/msal-node";
import "dotenv/config"; // process.env now has the values defined in a .env file

const clientAssertionCallback: msal.ClientAssertionCallback = async (
    config: msal.ClientAssertionConfig
): Promise<string> => {
    // network request that uses config.clientId, (optionally) config.tokenEndpoint, and (optionally) config.fmiPath
    const result: Promise<string> = await Promise.resolve(
        "network request which gets assertion"
    );
    return result;
};

const clientConfig = {
    auth: {
        clientId: "your_client_id",
        authority: "your_authority",
        clientSecret: process.env.clientSecret, // OR
        clientCertificate: {
            thumbprintSha256: process.env.thumbprint,
            privateKey: process.env.privateKey,
        }, // OR
        clientAssertion: clientAssertionCallback, // or a predetermined clientAssertion string
    },
};
const cca = new msal.ConfidentialClientApplication(clientConfig);
```

### Switch MSAL Node.js to ConfidentialClientApplication

Source: https://github.com/azuread/microsoft-authentication-library-for-js/blob/dev/samples/msal-node-samples/silent-flow/README.md

Modify the MSAL Node.js initialization from PublicClientApplication to ConfidentialClientApplication when using a client secret. This is necessary for confidential clients.

```javascript
// Change this
const publicClientApplication = new msal.PublicClientApplication(clientConfig);
const msalTokenCache = publicClientApplication.getTokenCache();
return getTokenSilent(config, publicClientApplication, null, msalTokenCache);

// To this
const confidentialClientApplication = new msal.ConfidentialClientApplication(
    clientConfig
);
const msalTokenCache = confidentialClientApplication.getTokenCache();
return getTokenSilent(
    config,
    confidentialClientApplication,
    null,
    msalTokenCache
);
```

### Configure ConfidentialClientApplication

Source: https://github.com/azuread/microsoft-authentication-library-for-js/blob/dev/samples/msal-browser-samples/HybridSample/README.md

Initializes the MSAL Node confidential client with environment-based credentials and logging configuration.

```typescript
const dotenv = require("dotenv");
const msal = require("@azure/msal-node");
dotenv.config();

const cca = new msal.ConfidentialClientApplication({
    auth: {
        clientId: process.env.MSAL_CLIENT_ID,
        authority: process.env.MSAL_AUTHORITY,
        clientSecret: process.env.MSAL_CLIENT_SECRET,
    },
    system: {
        loggerOptions: {
            loggerCallback: (loglevel, message, containsPii) => {
                console.log(message);
            },
            piiLoggingEnabled: false,
            logLevel: msal.LogLevel.Verbose,
        },
    },
});
```

### Initialize ConfidentialClientApplication

Source: https://github.com/azuread/microsoft-authentication-library-for-js/blob/dev/samples/msal-node-samples/b2c-user-flows/README.md

Set up the configuration object and instantiate the MSAL ConfidentialClientApplication class.

```javascript
const confidentialClientConfig = {
    auth: {
        clientId: config.authOptions.clientId,
        authority: config.policies.authorities.signUpSignIn.authority,
        clientSecret: process.env.CLIENT_SECRET,
        knownAuthorities: [config.policies.authorityDomain],
    },
};

// Create an MSAL PublicClientApplication object
const confidentialClientApp = new msal.ConfidentialClientApplication(
    confidentialClientConfig
);
```

### Initialize Confidential Client Application

Source: https://github.com/azuread/microsoft-authentication-library-for-js/blob/dev/lib/msal-node/docs/initialize-confidential-client-application.md

Configuration options for MSAL Node include common parameters and specific parameters for each authentication flow. The `clientId` is mandatory for initializing a confidential client application. The `authority` defaults to 'https://login.microsoftonline.com/common/' if not explicitly set. A client credential is also mandatory for confidential clients, which can be provided as a `clientSecret`, a `clientCertificate` (requiring `thumbprintSha256` and `privateKey`), or a `clientAssertion`.
